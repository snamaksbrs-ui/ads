# سوق سنام — سوق إعلانات مبوبة على Blogger

## قاعدة بيانات Supabase
أُضيف ملف `supabase/schema.sql` لإنشاء قاعدة البيانات الأساسية للمنصة، ويشمل:
- حسابات وملفات المستخدمين.
- الأقسام والإعلانات وحالات المراجعة.
- صور الإعلانات.
- المفضلة والإعجابات والتعليقات والبلاغات.
- سياسات Row Level Security لحماية البيانات.
- مخزن صور عام باسم `ad-images` مع حد 5 ميجابايت للملف وأنواع صور محددة.

### تفعيل قاعدة البيانات
1. أنشئ مشروعاً في [Supabase](https://supabase.com/).
2. افتح SQL Editor في مشروعك.
3. الصق محتوى الملف `supabase/schema.sql` وشغّله مرة واحدة.
4. من Project Settings ← API انسخ Project URL و anon/public key.
5. لا تشارك Service Role Key ولا تضعه في قالب Blogger أو المتصفح؛ المفتاح العام فقط يستخدم في الواجهة مع سياسات RLS.

> ملاحظة: إضافة مخطط قاعدة البيانات لا تعني أن واجهة Blogger أصبحت متصلة تلقائياً. يلزم تزويد إعدادات المشروع العامة (Project URL و anon/public key) لإتمام ربط JavaScript في القالب واختبار القراءة والإرسال وتسجيل الدخول.

## ما أُضيف في القالب حالياً
- واجهة سوق داخل الصفحة الرئيسية وليست صفحة تعريفية فقط.
- قراءة منشورات بلوجر المعروضة في الصفحة وتحويلها إلى بطاقات سوق؛ منشورات بلوجر هي مصدر الإعلانات المنشورة حالياً.
- 15 إعلاناً تجريبياً موزعة على العقارات والسيارات والأجهزة والوظائف والأثاث والخدمات.
- بطاقات إعلانات مع السعر والمدينة والقسم والتاريخ، ونافذة تفاصيل لكل إعلان.
- تصفية الإعلانات حسب القسم والبحث النصي.
- نموذج «أضف إعلانك» يعمل دون تسجيل دخول في وضع العرض التجريبي.
- منشورات Blogger الأصلية تظل موجودة في المدونة ويمكن عرضها أسفل واجهة السوق.

## استخدام بلوجر كمخزن للإعلانات
يمكنك استخدام منشورات Blogger نفسها كسجلات للإعلانات: أنشئ منشوراً لكل إعلان من لوحة بلوجر، وضع له تسمية القسم المطابقة تماماً (عقارات، سيارات، أجهزة، وظائف، أثاث، خدمات). القالب يقرأ منشورات المدونة ويعرضها كبطاقات في السوق. اكتب السعر بصيغة `السعر: 2500 ريال` والمدينة بصيغة `المدينة: الرياض` داخل وصف المنشور لتحسين استخراج بيانات البطاقة. الصور والوصف والرابط الأصلي تؤخذ من المنشور.

## تنبيه عن النشر الحالي
قبل اكتمال ربط Supabase، نموذج الإضافة التجريبي يحفظ معاينة الإعلان في `localStorage` على نفس المتصفح والجهاز، وهذا ليس نشراً عاماً. الإعلانات التجريبية بيانات افتراضية وليست عروضاً حقيقية.

## تثبيت القالب
1. خذ نسخة احتياطية من مظهر Blogger الحالي.
2. افتح Blogger ← المظهر ← استعادة/تحميل، ثم ارفع `sanam-taqib-e-services-platform.xml`.
3. اختبر الرئيسية والأقسام والبحث ونافذة التفاصيل على الهاتف والكمبيوتر.

## ملاحظات الأمان والتشغيل
- الإعلانات المرسلة عبر الزوار تُسجل بحالة `pending` ولا تظهر للعامة إلا بعد الموافقة.
- المفضلة والإعجابات تتطلب حساباً مسجلاً.
- التعليقات تتطلب تسجيل الدخول وتنتظر المراجعة.
- يجب تقييد رفع الصور والتحقق من نوعها وحجمها، وإضافة حماية إضافية من السبام ومراجعة البلاغات قبل الإطلاق العام.
- لا تضع مفاتيح Service Role أو كلمات المرور أو أسرار OAuth في القالب.
