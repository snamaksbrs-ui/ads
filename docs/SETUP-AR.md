# سوق سنام — قالب إعلانات مبوبة لبلوجر

هذا الفرع يحتوي على قالب Blogger عربي بتصميم سوق إعلانات مبوبة قريب من نمط مواقع الإعلانات المحلية، مع إبقاء منشورات Blogger هي مصدر الإعلانات.

## ما يعمل داخل القالب
- واجهة عربية RTL متجاوبة، بحث بلوجر، أقسام مبنية على تسميات المنشورات.
- بطاقات الإعلانات تُعرض من منشورات المدونة الموجودة.
- صفحة الإعلان تستخدم صفحة المنشور الأصلية في Blogger.
- التعليقات عبر نظام تعليقات Blogger (بحسب إعدادات المدونة).
- زر إعجاب محلي لكل متصفح/جهاز. **هذا ليس عداد إعجابات عاماً ولا يتزامن بين الزوار**.
- أزرار إضافة الإعلان تشير إلى صفحة /p/submit-ad.html.

## إعداد بلوجر
1. من Blogger افتح المظهر ← الاحتفاظ بنسخة احتياطية، ثم استعادة/تحميل ملف `sanam-taqib-e-services-platform.xml`.
2. فعّل التعليقات في الإعدادات، واضبط من يمكنه التعليق والمراجعة.
3. أنشئ منشورات الإعلانات كمنشورات Blogger. اجعل عنوان المنشور اسم السلعة/الخدمة، وأضف الصور والسعر والمدينة والوصف في المحتوى.
4. أضف تسمية واحدة أو أكثر مطابقة للأقسام: `عقارات`، `سيارات`، `أجهزة`، `وظائف`، `أثاث`، `خدمات`.
5. أنشئ صفحة Blogger بعنوان "أضف إعلانك" وبالرابط الثابت `submit-ad`. وضّح فيها أن إرسال الإعلان حالياً يتم عبر حساب محرر/كاتب معتمد في Blogger، ثم اربط الزر بإجراء النشر المتاح للمحررين.

## حدود تقنية مهمة — لا يدّعي القالب غير الموجود
Blogger لا يوفر في القالب وحده واجهة آمنة لإنشاء حسابات أعضاء مستقلة أو نشر منشورات عامة للزوار المجهولين. لذلك لا يمكن اعتبار تسجيل الأعضاء، النشر الذاتي للزوار، الإعجابات المشتركة، الرسائل الخاصة، الإبلاغ/الحظر، أو لوحة تحكم المعلنين مفعّلة بمجرد رفع XML.

لتحويله إلى سوق كامل بمستوى حراج، يلزم ربط خدمة خلفية مستقلة (مثل Firebase أو Supabase) مع قواعد صلاحيات وتخزين صور ومراجعة محتوى، أو بناء واجهة وسيطة تتعامل مع Blogger API عبر خادم آمن. لا تضع مفاتيح سرية في القالب أو JavaScript العام.

## اختبار قبل الإطلاق
- جرّب استيراد XML في مدونة تجريبية أولاً.
- اختبر الصفحة الرئيسية وصفحة التصنيف وصفحة إعلان والتعليقات على الجوال.
- زر الإعجاب الحالي يخزن الاختيار في localStorage على الجهاز نفسه فقط؛ مسح بيانات المتصفح أو استخدام جهاز آخر يعيد الحالة.
