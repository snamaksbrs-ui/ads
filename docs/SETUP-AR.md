# سوق سنام — قالب إعلانات مبوبة لبلوجر

هذا القالب يحوّل واجهة Blogger إلى سوق إعلانات مبوبة عربي. منشورات Blogger هي مصدر الإعلانات.

## ما يعمل في القالب
- واجهة عربية RTL متجاوبة، بحث Blogger وأقسام حسب تسميات المنشورات.
- عرض منشورات الإعلانات على الصفحة الرئيسية وصفحات الأقسام.
- صفحة تفاصيل لكل إعلان عبر رابط المنشور الأصلي.
- التعليقات عبر نظام تعليقات Blogger بحسب إعدادات المدونة.
- زر إعجاب يحفظ اختيار الزائر محلياً في المتصفح الحالي فقط؛ لا يوجد عدّاد عام متزامن.

## الإعداد
1. خذ نسخة احتياطية من مظهر مدونتك.
2. في Blogger افتح المظهر ثم استعادة/تحميل، وارفع `sanam-taqib-e-services-platform.xml`.
3. فعّل التعليقات واضبط من يمكنه التعليق والمراجعة.
4. انشر كل إعلان كمنشور Blogger، وضع له تسمية مناسبة: `عقارات`، `سيارات`، `أجهزة`، `وظائف`، `أثاث` أو `خدمات`.
5. أضف الصور والسعر والمدينة ووسيلة التواصل داخل محتوى المنشور.
6. أنشئ صفحة ثابتة برابط `submit-ad` بعنوان «أضف إعلانك». إلى حين ربط بوابة نشر آمنة، يكون النشر الفعلي عبر حساب محرر/كاتب Blogger معتمد.

## وظائف تحتاج خادماً خارجياً
قالب Blogger وحده لا يوفّر حسابات أعضاء مستقلة، ولا يسمح بأمان للزوار المجهولين بإنشاء منشورات تلقائياً، ولا يوفر تخزين إعجابات مشتركاً بين الأجهزة أو رسائل خاصة ولوحة تحكم للمعلنين. لإكمال سوق بمستوى حراج يجب ربط Firebase أو Supabase (أو خادم خاص) مع صلاحيات وقاعدة بيانات وتخزين صور ومراجعة محتوى، واستخدام Blogger API من الخادم فقط عند الحاجة. لا تضع مفاتيح سرية داخل القالب.

## قبل الإطلاق
اختبر استيراد القالب في مدونة تجريبية، ثم اختبر الرئيسية والتصنيفات وصفحة الإعلان والتعليقات على الهاتف والكمبيوتر. زر الإعجاب الحالي محلي وليس دليلاً على عدد إعجابات جميع الزوار.
