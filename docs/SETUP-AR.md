# سوق سنام — منصة إعلانات Blogger متصلة بـ Supabase

## الربط الموجود في القالب
تم ربط قالب `sanam-taqib-e-services-platform.xml` بمشروع Supabase المحدد:
- قراءة الإعلانات المعتمدة من جدول `ads` مع الأقسام.
- عرض إعلانات Blogger والإعلانات التجريبية إلى جانب إعلانات Supabase.
- إرسال إعلان جديد كزائر أو مستخدم مسجل بحالة `pending` حتى يوافق المشرف عليه.
- تسجيل الدخول وإنشاء حساب بالبريد الإلكتروني وكلمة المرور عبر Supabase Auth.
- إضافة المفضلة والإعجاب للمستخدمين المسجلين.
- عرض التعليقات المعتمدة وإرسال تعليق جديد للمراجعة.
- رفع صورة JPG/PNG/WebP للمستخدم المسجل إلى Storage، بحد أقصى 5 ميجابايت، أو استخدام رابط صورة.
- لا تزال الإعلانات التجريبية واضحة بوصفها بيانات توضيحية، ولا تُحفظ إعلانات الزوار في localStorage.

## إعداد قاعدة البيانات (مطلوب مرة واحدة)
1. افتح مشروع Supabase المرتبط بالقالب.
2. افتح SQL Editor.
3. شغّل الملف كاملاً: `supabase/schema.sql`.
4. تأكد أن الجداول ظهرت في Table Editor: `categories`, `profiles`, `ads`, `ad_images`, `favorites`, `likes`, `comments`, `reports`.
5. تأكد من وجود Storage bucket باسم `ad-images`.
6. في Authentication ← Providers تأكد من تفعيل Email. إذا كان تأكيد البريد مفعلاً، يجب على المستخدم تأكيد بريده قبل تسجيل الدخول.
7. في إعدادات Authentication أضف نطاق مدونة Blogger إلى Site URL وRedirect URLs إذا كنت تستخدم روابط إعادة التوجيه لتأكيد البريد.

## اختبار الربط بعد تشغيل SQL
1. افتح الصفحة الرئيسية للمدونة وحدّث الصفحة.
2. يجب أن تتغير حالة الاتصال إلى `متصل بقاعدة البيانات` ويظهر عدد الإعلانات المنشورة من Supabase.
3. أنشئ حساباً تجريبياً من زر «دخول / إنشاء حساب».
4. أرسل إعلاناً تجريبياً؛ يجب أن يُحفظ بحالة `pending` ولا يظهر للعموم قبل الموافقة.
5. من Supabase Table Editor افتح جدول `ads` وغيّر حالة الإعلان التجريبي إلى `approved`؛ ثم حدّث السوق للتأكد من ظهوره.
6. جرّب رفع صورة بحساب مسجل، ثم جرّب الإعجاب والمفضلة والتعليقات.
7. جرّب نافذة خاصة لتتأكد أن الإعلان المعتمد يظهر للزوار غير المسجلين.

## مراجعة الإعلانات
إعلانات الزوار لا تُنشر مباشرة. لمراجعتها افتح Supabase ← Table Editor ← `ads`، وغيّر `status` إلى:
- `approved` لإظهار الإعلان.
- `rejected` لرفضه.
- `sold` عند البيع.
- `archived` لإخفائه.

التعليقات تُحفظ بحالة `pending` وتحتاج إلى تغييرها إلى `approved` حتى تظهر.

## الأمان
- المفتاح المضمن في قالب Blogger هو Publishable/anon key، وهو مفتاح واجهة عامة مخصص للاستخدام في المتصفح، وتتحكم سياسات RLS في صلاحياته.
- لا تضع أبداً Service Role key أو مفاتيح سرية أو كلمات مرور في قالب Blogger.
- رفع الملفات يتطلب تسجيل الدخول، وتتحقق سياسة Storage من مجلد المستخدم.
- نشر الإعلان متاح للزائر دون تسجيل، لكنه ينتظر المراجعة. قبل الإطلاق العام أضف حماية من السبام وحدوداً لمعدل الطلبات ومراجعة للبلاغات.
- لا تعتمد على الصور أو معلومات الاتصال في الإعلانات التجريبية؛ فهي أمثلة افتراضية.

## ملفات المشروع
- `sanam-taqib-e-services-platform.xml`: قالب Blogger المتصل بـ Supabase.
- `supabase/schema.sql`: الجداول والعلاقات وسياسات RLS والتخزين والصلاحيات.
- `docs/SETUP-AR.md`: دليل الإعداد والاختبار.
