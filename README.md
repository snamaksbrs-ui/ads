# سوق سنام — قالب إعلانات مبوبة لـ Blogger

قالب عربي RTL متجاوب يحوّل مدونة Blogger إلى واجهة سوق للإعلانات المبوبة، مع أقسام للعقارات والسيارات والأجهزة والوظائف والأثاث والخدمات.

## ما الذي يقدمه القالب؟

- واجهة رئيسية عربية مع بحث مرتبط ببحث Blogger.
- روابط تصنيفات مرتبطة بتسميات Blogger.
- عرض منشورات المدونة بوصفها إعلانات، مع صفحات الإعلان والصور والتسميات.
- دعم التعليقات الأصلية في Blogger على صفحات الإعلانات.
- زر «أضف إعلانك» يوجّه إلى صفحة نشر مخصصة.
- الإبقاء على بنية Blogger الأصلية وعناصر القالب لتسهيل التثبيت والإدارة.

## التثبيت

1. افتح لوحة Blogger ثم **المظهر**.
2. اختر **استعادة** ثم ارفع الملف `sanam-taqib-e-services-platform.xml`.
3. بعد التثبيت، افتح **الإعدادات > المشاركات والتعليقات** وفعّل التعليقات وحدد سياسة التعليق المناسبة.
4. أنشئ تسميات مطابقة للأقسام المستخدمة في القالب: `عقارات`، `سيارات`، `أجهزة`، `وظائف`، `أثاث`، `خدمات`.
5. أنشئ صفحة Blogger بعنوان «أضف إعلانك» وبالمسار `/p/submit-ad.html`، أو غيّر رابط الزر في القالب إلى رابط صفحة الإرسال لديك.

## حدود Blogger والتكامل المطلوب للنشر العام

قالب XML وحده لا يستطيع إنشاء منشور Blogger جديد باسم زائر مجهول أو منح الزائر صلاحية النشر. واجهة Blogger لا توفر نموذج نشر عام مباشر داخل القالب. لذلك:

- **التعليقات:** تعمل من خلال نظام تعليقات Blogger الأصلي، ويمكن للزوار التعليق وفق إعداداتك.
- **تسجيل الدخول:** تسجيل الدخول الذي يظهر أثناء التعليق يخضع لتكامل Google/Blogger وإعدادات التعليقات؛ القالب لا ينشئ قاعدة عضويات مستقلة.
- **إضافة إعلان من الزائر:** يلزم إنشاء نموذج إرسال وربطه بخدمة وسيطة آمنة (مثل Google Apps Script أو خادم خاص) تستخدم Blogger API. يفضّل أن ترسل الإعلانات أولاً إلى المراجعة كمسودات، ثم ينشرها المشرف بعد التحقق منها. لا تضع بيانات OAuth أو مفاتيح سرية داخل JavaScript القالب.
- **الإعجاب:** لا يوفّر Blogger زر إعجاب عاماً موحداً للزوار في القالب. يلزم تخزين مركزي عبر خدمة خلفية لمنع تكرار الإعجاب ومزامنة العدد بين الأجهزة؛ التخزين المحلي وحده ليس عدّاد إعجابات حقيقياً.

## طريقة تنسيق الإعلانات

أنشئ كل إعلان كمنشور Blogger مستقل:
- عنوان واضح يتضمن السلعة أو الخدمة والمدينة عند الحاجة.
- صورة رئيسية في بداية المنشور.
- وصف وسعر ومدينة ووسيلة تواصل ضمن المحتوى.
- أضف تسمية القسم المناسبة حتى يظهر الإعلان ضمن التصنيف الصحيح.
- فعّل التعليقات إذا رغبت في استقبال الاستفسارات.

## الفرع
