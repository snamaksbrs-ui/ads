# Pixel Blogger theme adaptation for Souk Sanam

Customized Arabic/RTL adaptation of the Pixel Blogger template by Colorlib.

- Upstream: https://github.com/puikinsh/Pixel-Blogger-Template
- Original author: Colorlib
- Original license: GNU General Public License v3.0 (GPL-3.0)
- Upstream template version: 2.4.1
- Adaptations: Arabic brand copy, RTL-friendly presentation, Tajawal typography, category navigation, and neutral marketplace styling.

The existing Blogger/Supabase-integrated marketplace theme remains at the repository root. The Pixel-derived file is an additional visual variant and does not replace the existing integration or claim to include its Supabase workflows.
