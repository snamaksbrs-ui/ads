# Phoenix Blogger Theme attribution

The original template in `phoenix-original.xml` and the adapted template in `sanam-editorial-ar.xml` are based on [Phoenix Blogger Theme](https://github.com/mikites8-source/phoenix-blogger-theme) by Mikiyas Tesfaye.

Upstream license: MIT. The upstream license text is included in `PHOENIX-LICENSE`.

The adapted version changes the visual palette, Arabic typography, and Arabic/RTL interface labels and styling. Blogger runtime behavior and all original template logic remain subject to validation in a test blog before production use.
